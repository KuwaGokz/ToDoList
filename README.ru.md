# ToDoList V0 

[English version](README.md)

Простой туду-лист: REST-подобный JSON API на Go (только стандартная библиотека) и небольшая страница на HTML + чистом JS.

Мой первый пет-проект, поэтому он ещё в разработке. 🚧

![Скриншот](screenshots/app.png)

## Возможности

- Добавить задачу с названием и необязательным описанием
- Отметить задачу выполненной / невыполненной
- Удалить задачу

## Запуск

Нужен Go 1.22+ (используется маршрутизация «метод + путь» из стандартного `net/http`).

```
go run ./cmd/main.go
```

После этого открой http://127.0.0.1:8080 в браузере.

## API

CRUD поверх JSON:

| Метод  | Путь          | Тело                                | Описание             |
|--------|---------------|-------------------------------------|----------------------|
| GET    | `/tasks`      | -                                   | Список всех задач    |
| POST   | `/tasks`      | `{"title": "...", "message": "..."}`| Создать задачу       |
| PATCH  | `/tasks/{id}` | `{"status": true}`                  | Изменить статус      |
| DELETE | `/tasks/{id}` | -                                   | Удалить задачу       |

## Примечания

- Задачи хранятся в слайсе в памяти, поэтому **при перезапуске все данные пропадают**.
- Слайс защищён мьютексом от одновременного доступа.
- Сервер слушает только localhost. Авторизации и HTTPS нет, валидация минимальная. Проект учебный.
